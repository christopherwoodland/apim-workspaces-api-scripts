# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Report vulnerabilities to the Microsoft Security Response Center (MSRC):

- [https://msrc.microsoft.com/report/vulnerability](https://msrc.microsoft.com/report/vulnerability)

You may also review Microsoft security guidance:

- [https://www.microsoft.com/msrc](https://www.microsoft.com/msrc)

## What to Include

Please include as much detail as possible:

- Affected script or file path
- Reproduction steps
- Impact assessment
- Logs or stack traces (without secrets)
